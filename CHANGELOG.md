# Changelog

## 1.1.0

- Additive native apiKeyProvider resolves a fresh nonempty credential per send or duplex connection; blank callbacks fail before send. Metadata failures do not invoke the supplier again for authentication classification. HTTP language/stream and client-secret paths preserve caller AbortError/TimeoutError equivalents; native AIAbortError, CancellationError and Foundation cancellation/timeout errors retain identity instead of becoming Gateway 500 errors. Upstream text/audio input failures reach speech/transcription output streams and close sockets, including task cancellation rather than leaving transcription output pending. Speech/transcription WS connections resolve credentials after case-insensitive caller header overrides, preserve auth subprotocols, recheck abort after async supplier and release input on connection/supplier failure. Reviewed upstream: @ai-sdk/gateway 4.0.126 to 4.0.132. Validation passed: node Scripts/test-packages.mjs (all 52 owning package suites and the compatibility facade); node Scripts/sdk.mjs generate --check; node --test Scripts/tests/*.test.cjs (27 passed); docs-site check and build (100 pages). Live provider calls were not run.
  Compatibility: Minor release for additive native API; existing static settings and call sites remain compatible. Updated direct dependency minimums are recorded in the manifest. Existing documented JS/framework and native product gaps remain; version-delta review does not imply full parity or live-service testing. Explicit custom authentication skips an unused credential supplier, a deliberate native callback-order adaptation.
